# Bloom Atelier

### Luxury Bridal Bouquet E-Commerce Website

A full-stack e-commerce portfolio project featuring a responsive shopping experience for a luxury bridal floral brand. Designed and developed with a focus on clean UI, usability, and modern web technologies.

**Live Website:** [Bloom Atelier](https://production.d1wuexprmnngok.amplifyapp.com)

## Tech Stack

**Frontend**
- React
- TypeScript
- Tailwind CSS
- TanStack Router
- Firebase Authentication
- Axios

**Backend**
- Java, Spring Boot
- MySQL
- REST APIs

**Deployment**
- AWS Amplify (Frontend)
- AWS EC2 and AWS RDS (Backend & Database)
- Docker

## Key Features

- Responsive product catalogue and product detail pages
- Product search functionality
- Shopping bag with add, update quantity, and remove features
- Firebase user authentication
- Protected checkout flow with form validation
- Delivery date validation
- Order confirmation flow
- Frontend integration with Spring Boot REST APIs

## Project Highlights

- Designed a refined, minimal user interface inspired by luxury retail experiences.
- Developed reusable React components with TypeScript and Tailwind CSS.
- Integrated frontend components with backend APIs for product and checkout functionality.
- Implemented responsive layouts for desktop and mobile devices.
